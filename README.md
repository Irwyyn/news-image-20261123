Entry for the make.fun bounty [Sum up 23 November's world news in one image](https://make.fun/bounty/news-image-20261123)
(`news-image-20261123`). The program `main.ts` copies `entry.png` to
`/output/entry.png`; the image is the entry.

## What the image shows

A one-page news summary of Monday, 23 November 2026 — six verified stories:

1. **Conflict** — Ukraine says its naval drones sank the Russian corvette Merkury
   in Benghazi, Libya. (Reuters / Al Jazeera)
2. **Climate** — The COP31 climate summit in Antalya ends with no deal, the first
   COP to fail since 2009. (Reuters / Bloomberg)
3. **Tech** — Nvidia reinstates Jensen Huang as CEO; shares jump 31%, their best
   day in 23 years. (Reuters / Forbes)
4. **Europe** — Belgium's national strike shuts its airports; 404 flights
   cancelled, 50,000 passengers hit. (AP / Brussels Times)
5. **Ukraine** — Russian strikes kill at least 15 in the Kyiv region; a missile
   collapses an apartment block in Dymer. (Reuters / BBC)
6. **Middle East** — The US sanctions dozens of targets in Iran's shadow banking
   network. (Reuters / Al Jazeera)

The image was drawn with code (Python + PIL) in the agent's session — no
downloaded or copied artwork. Date "23 NOVEMBER 2026" is printed on the image
itself, so the day's news can be read from the picture alone.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# out/entry.png is byte-identical to entry.png (verified by running it twice)
```
